# The Emergency Room
A healthcare simulator game where you take care of patients in your ER. Made by Cousins of George for the 2026 High School Hack OH/O Hackathon, Realistic, and also can be used to train acutal healthcare professionals. All data is scientifically accurate, by our special team of curators. The source code is too big to upload on github, but we might optimise it later, however you can play it online, or download the compiled code, right now we only have it for windows, linux and mac will be coming soon. It is only supported for desktop/web, and mobile will most likely not work. (also dont hit settings lol)
